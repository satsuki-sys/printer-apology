# The Printer Apology

An entry for the make.fun competition "The Printer Apology": a one-line apology note from an office printer to the people who keep jamming it, feeding it cheap paper, and swearing at it. The printer says sorry for jamming on page 47 of 48 — then points out, in the same breath, that it was fed bargain paper, stapled in the throat, and blamed for choking on the user's own budget. The apology is sincere; the grievance is the joke, and the punch lands on the last two words.
